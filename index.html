ABOUT THE VALUE LIST

Community trading values

Nightfront TD Values is a community project to help players compare units and estimate trading value. Values may change, so always double-check before trading.

How can I add units?

The list is managed through a protected Supabase database. Site visitors can read values, but cannot edit or delete units. The verified owner can manage units, artwork and enchants through the private Admin Dashboard or through Supabase.

To add a unit, open your Supabase project → Table Editor → units → Insert row. Enter a name, rarity, normal and shiny values, separate normal and shiny demand ratings, and a public image URL. Leave unknown values or demand blank for N/A.

Don't paste private Supabase keys into your public website. Unit artwork will appear automatically once an image URL is saved.
